# agentic_dev 認証分離の実装・検証（2026-10-18）

## 構成

- CLI コンテナ `ai-lab-agent:1`: Claude Code、専用認証ボリューム、試行専用 IPC ボリューム。作業コピーと非公開テストのマウントなし。Docker bridge ネットワーク。
- 作業コンテナ `ai-lab-agent-worker:1`: 作業コピー、公開テストの読み取り専用マウント、IPC ボリューム。認証ボリュームと Docker ソケットなし。`--network none`。
- 固定 MCP は `list_files`、`read_file`、`write_file`、`run_public_tests` の4操作のみ。ファイル操作は `src/` と `public_tests/` に限定し、書込は `src/` の Python ファイルのみ。公開テストは固定 pytest コマンドを実行する。
- Claude Code は `--tools ""`、`--restricted`、`--strict-mcp-config`、`--allowedTools`、`--permission-mode dontAsk`、`--disable-slash-commands` を指定。CLI と作業コンテナは試行専用 Unix ソケットで接続する。IPC ボリュームは試行後に削除する。
- 非公開採点は既存の分離コンテナで行い、作業コピーと非公開テストを読み取り専用でマウントする。課題、初期状態、テスト、比較条件、履歴・時間・トークン・費用集計は維持した。

## 検証結果

- Docker イメージ2種をビルド。CLI コンテナの `claude --version` と `api.anthropic.com:443` への TLS 到達を確認。ダミー認証情報のため、認証済み API 呼び出しは検証していない。
- ダミー認証情報は CLI 専用ボリュームにだけ置いた。作業コンテナから認証ファイル、Docker ソケット、非公開テスト、元リポジトリを参照できず、外部接続も失敗した。
- MCP から認証ファイルへの絶対パス、作業領域外への `..`、公開テストへの書込を拒否した。拒否応答と抽出した操作履歴にダミー認証値は含まれなかった。
- 2課題×2モデル条件の4 dry-run で、初期状態の公開・非公開テスト失敗と参照実装の両テスト成功、作業成果物の回収を確認。実モデルは呼び出していない。
- Docker 専用テスト4件成功。全体の自動テストは `PYTHONUTF8=1` で758件成功、Docker専用4件は環境変数未設定のためスキップ。UTF-8を設定しないと既存の別実験テスト1件がWindowsのcp932デコードで失敗する。

## 残るリスク

- ダミー認証情報では、Claude Code が実認証でMCPツールをモデルに提示し、API通信後も組み込みツールを使わせないことの実行時確認はできない。公式CLIヘルプで指定フラグの意味を確認したが、実モデル試行前の制限で本番セッション自体は未実行。
- Docker DesktopとホストOSの隔離に依存する。ホスト上の試行ディレクトリには成果物と操作履歴が保存される。
