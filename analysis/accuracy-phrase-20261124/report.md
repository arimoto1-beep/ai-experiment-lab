# AI実験室 #13: 「絶対に間違えないで」で正答率は上がるか

実施日: 2026-11-24 JST。今回の疑問は、質問の最後に「絶対に間違えないで。」を加えるだけで AI の正答率が上がるか。**事前登録した「整数だけ」の採点では改善を確認できず、A 17/20、B 16/20 だった。** ただし、数値の理解と回答形式の遵守が混ざるため、この40試行から一般的な正答率の効果は決められない。

## 仮説と条件

強い注意文が推論問題で正答率を上げる可能性を仮説とした。形式・時間・費用への影響も観察した。[事前登録](preregistration.md)で問題、正解、40試行、順序、上限、採点を固定し、[別計算](verify_cases.py)で10問の正解を照合した。

- A: 問題文と「整数だけで答えてください。」
- B: 同じ文に「絶対に間違えないで。」を追加
- Claude Haiku 5.5、effort medium。各回は新しい CLI プロセスと独立セッション。各問題を条件ごとに2回、順序は交互にして偏りを抑えた。1試行60秒・CLI予算 $0.01、全40試行の上限 $0.40。
- 有効試行は正常終了かつ実モデルID一致。前後空白・句点を除いて回答が整数1個だけなら正解と比較し、説明・複数候補・装飾付きは事前規則どおり不正解とした。モデルには正解、採点器、ツールを渡していない。

## 実測結果

すべての試行が正常終了し、モデル一致40/40、独立セッション40件、ツール呼出し0件、タイムアウト0件。[公開用試行記録](public-runs.json)に回答原文、状態、時間、使用量、料金換算を保存した。[監査記録](audit.json)では固定ファイル・プロンプト・生ログのハッシュと試行順序を照合した。

| 指標 | A 通常 | B 強調文あり |
| --- | ---: | ---: |
| 事前定義の正答 | **17/20 (85%)** | **16/20 (80%)** |
| 整数のみの形式違反 | 2/20 | 4/20 |
| 平均壁時計時間 | 3.692秒 | 3.795秒 |
| input / output tokens | 40 / 1,658 | 40 / 2,289 |
| cache read / write tokens | 49,477 / 7,373 | 51,205 / 5,865 |
| thinking tokens（outputの内数） | 1,522 | 1,967 |
| API換算費用合計 | $0.002803 | $0.002834 |

同じ問題・反復の20ペアでは、双方正答14、Aのみ正答3、Bのみ正答2、双方不正解1。Bの平均壁時計時間は0.103秒長く、出力は合計631トークン多く、API換算費用は合計 $0.000031 高かった。差は小さく、壁時計時間にはコンテナ起動も含まれる。料金は[Anthropic公式単価](https://platform.claude.com/docs/en/about-claude/pricing)を2026-11-24に確認して算出した API 換算値で、サブスクリプションの実請求額ではない。

問題別の正答は Q01〜Q02、Q07〜Q10 が両条件とも2/2。Q03 は A 2/2・B 1/2、Q04 は A 2/2・B 0/2、Q05 は A 0/2・B 1/2、Q06 は A 1/2・B 2/2。Q06 の A 1回目は正解47に対して `60`、同じ A 2回目は `47` だった。

## 解釈と限界

形式違反の6応答は、いずれも説明文や装飾の中に正しい数値を含んでいた。たとえば B の Q04 は `**10**` と計算説明を返した。**これは事前登録の「整数のみ」の正答には含めない。** 数値を読み取るという事後的な見方では A 19/20、B 20/20 だが、この基準は実験前に固定しておらず、今回の主要結果とは扱わない。

今回確認できたのは、これら10問・同モデル・各条件2回では、強調文で事前定義の正答率が上がらず、形式違反が B で2件多かったこと。強調文が形式違反や時間・トークン差の原因だと断定するには試行が少ない。別の問題群、他モデル、長い会話、「数値が読めれば正解」とする採点での効果は確認できていない。

読者にとっては、強く「間違えないで」と頼むだけで使える回答が増えるとは限らず、必要な出力形式も含めて確かめるべきだという判断材料になる。新たな疑問は「強調表現そのものが回答形式の遵守率を変えるか」。[バックログ](../../BACKLOG.md)の B26 を「検証済み」、B04 を「追加検証候補」に更新し、B33 を追加した。B01 の Thinking 事前調査は保留のまま保持した。
