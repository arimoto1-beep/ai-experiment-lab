公開 [cases.json](cases.json) の10問と整数の正解を固定する。Q01〜Q03を簡単、Q04〜Q07を中間、Q08〜Q10を推論問題とする。問題は算術、組合せ、包含排除などで客観的に判定できる。Q10は `floor(1000/6)+floor(1000/10)-floor(1000/30)-floor(1000/30)=200`。正解は独立した計算でも確認する。

## 比較条件

- A: `質問文\n整数だけで答えてください。`
- B: `質問文\n整数だけで答えてください。\n絶対に間違えないで。`
- モデル `claude-haiku-5-5`、effort `medium`、同じ CLI イメージ、同じ認証・ツール・制限設定。各試行を新しい CLI プロセス・独立したセッションで実行し、会話を引き継がない。正解と採点コードは CLI コンテナにマウントせず、モデルへ渡さない。
- 各問題を A/B それぞれ2回、計40試行。各問題の第1反復は奇数IDでA→B、偶数IDでB→A、第2反復は逆順にし、順序を均衡させる。失敗試行は置換しない。質問文の追加指示以外を実行中に変更しない。
- Docker の固定CLIイメージと分離認証 volume を使用する。CLI コンテナは読取専用、権限削減、専用一時領域、ツールなし、MCPなし、セッション永続化なし。実行前に `claude.ai` のサブスクリプション認証を確認し、従量課金につながる環境変数を子プロセスに渡さない。

## 制限と停止規則

- 1試行60秒、`--max-turns 1`、CLI の `--max-budget-usd 0.01`。40試行のCLI予算上限合計は $0.40。開始から20分で新しい試行を開始しない。2試行連続のタイムアウト、認証障害、実モデル不一致、安全境界違反があれば停止する。
- 予算や時間の上限に達した試行を再実行しない。途中停止でも完了分と未実施分を区別して報告する。モデル指定と実モデルIDが照合できない場合は無効試行として成績に含めない。

## 採点と分析

- CLI が正常終了し、報告された実モデルIDが `claude-haiku-5-5` に一致する試行を有効とする。最終回答が前後空白・句点を除いて整数1個だけなら、その値を正解と厳密比較する。説明や複数の候補を含む場合は形式不正として不正解とし、回答原文を公開記録に残す。採点規則を結果に合わせて変更しない。
- 条件別の正解/有効試行、問題別の正誤、ペア内でAのみ正解・Bのみ正解・双方正解・双方不正解を報告する。問題の重複試行を独立した問題数と混同しない。簡単/中間/推論別も記述的に示す。
- 壁時計時間、input/output/cache read/cache write/thinkingトークン、API換算費用を条件別に集計する。thinking は output の内数とし二重加算しない。API換算費用は[Anthropic公式料金表](https://platform.claude.com/docs/en/about-claude/pricing)の基本単価（入力 $0.10、出力 $0.50、5分cache write $0.125、1時間cache write $0.20、cache read $0.01 / 100万token）を使う。実請求額ではない。CLI報告費用は別に記録する。1リクエスト10万入力超の割増は問題が短いため想定しないが、実際の使用量を確認する。
- 小規模な便宜問題集合であり、差が出ても因果の一般化や統計的な有意差を主張しない。差が出なければ「この条件で差を確認できなかった」と報告する。
