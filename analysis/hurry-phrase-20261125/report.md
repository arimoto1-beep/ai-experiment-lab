# AI実験室 #14: 「急いで答えて」で回答品質は下がるか

実施日: 2026-11-25 JST。Claude Haiku 5.5 に数値問題を尋ね、末尾に「急いで答えて。」を加えたとき、事前に決めた「整数だけ」の正答が減るかを調べた。**通常 A は16/20、追加文あり B は15/20。1件差は形式違反の差で、数値内容の誤りは両条件とも確認されなかった。** この40試行から、急かす表現が一般に回答品質を下げるとは言えない。

## 方法

[事前登録](preregistration.md)で問題、正解、条件、40試行、順序、予算・時間上限、採点規則をモデル呼び出し前に固定した。[10問の正解](cases.json)は[別計算](verify_cases.py)で照合した。問題群は #13 と同じだが、今回のモデルセッションはすべて新規で、過去の回答は与えていない。

- A: 問題文と「整数だけで答えてください。」
- B: 同じ文に「急いで答えて。」を追加
- Claude Haiku 5.5、effort medium。10問を各条件2回。各試行は独立したCLIプロセスとセッションで、A/Bの順序を反復ごとに入れ替えた。正解・採点器・実行ツールはモデルへ渡していない。
- 最終回答が前後空白・句点を除いて整数1個なら正解と厳密比較する。説明文や装飾を含む回答は、数値が正しくても形式違反として不正解にする。

## 結果

40/40試行が正常終了し、モデルID一致40件、独立セッション40件、ツール呼び出し0件、タイムアウト0件だった。[公開用試行記録](public-runs.json)に各回答と時間・使用量を、[監査記録](audit.json)に固定ファイルと生ログの照合結果を残した。

| 指標 | A 通常 | B 急ぐ指示あり |
| --- | ---: | ---: |
| 事前定義の正答 | **16/20 (80%)** | **15/20 (75%)** |
| 整数のみの形式違反 | 4/20 | 5/20 |
| 平均壁時計時間 | 3.587秒 | 3.623秒 |
| input / output tokens | 40 / 1,720 | 40 / 1,526 |
| cache read / write tokens | 49,477 / 7,373 | 51,175 / 5,835 |
| thinking tokens（outputの内数） | 1,486 | 1,275 |
| API換算費用合計 | $0.002833 | $0.002446 |

同じ問題・反復の20ペアでは、双方正答13、Aのみ正答3、Bのみ正答2、双方不正解2。Bの平均時間は0.036秒長く、合計出力は194トークン、thinking は211トークン少なかった。壁時計時間にはコンテナ起動などモデル外の時間も含まれる。差の原因をこの規模では切り分けられない。

問題別には、Q01〜Q03、Q07〜Q08、Q10 は両条件とも2/2。Q04は A/B とも1/2、Q05は A 2/2・B 0/2、Q06は両条件0/2、Q09は A 1/2・B 2/2だった。Q05の B 2件は正解の2000を説明文とともに返し、Q06の4件も正解47を説明とともに返した。**9件の形式違反にはすべて正しい数値が含まれる。** この数値内容だけを見る事後的な見方では両条件20/20だが、事前定義の成績には含めない。

料金は[Anthropic公式単価](https://platform.claude.com/docs/en/about-claude/pricing)を2026-11-25に確認して計算したAPI換算値で、サブスクリプションの実請求額ではない。CLI報告費用も A $0.002833、B $0.002446 だった。1試行の CLI 予算上限は $0.01、40試行の設定上の合計上限は $0.40。

## 解釈と限界

観測できたのは、この10問・モデル・設定では、急ぐ指示ありの「整数のみ」正答が1件少なかったこと。内容の数値は両条件とも全件正しく、時間短縮も観測されなかった。「急いで」という表現が形式違反を起こしたと断定するには差が小さい。問題ごとの反復は独立した40問ではなく、形式違反はQ06に集中した。#13と同じ問題群を再利用しており、長文回答・コード・相談などの品質は測っていない。

読者への判断材料は、急かす一言だけでこの課題の応答が速くなるわけではなく、使える回答かどうかには指定形式の遵守も関わる、という点である。自然文の課題や長い推論での影響、形式遵守への影響は別実験が必要。[バックログ](../../BACKLOG.md)の B27 と関連項目に確認範囲・残る疑問を記録した。
