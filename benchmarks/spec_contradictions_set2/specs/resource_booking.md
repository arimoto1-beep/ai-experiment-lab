# 施設予約・キャンセル・利用枠管理の仕様書

同一リリースの要件を示す。ID順・一般則より具体則という理由だけで優先順位を付けない。例外は対象IDを明記した規定だけとする。
有料法人予約と無料個人予約は別の契約区分である。施設の同時予約定員と、個人口座の月次無料利用枠は別の数量である。個室の同時予約定員は1件で、同じ時間帯に確定予約が1件存在するケースもある。
時間帯は開始を含み終了を含まない。通常個人予約の利用時間は60分とする。開始15分後に未チェックインの通常個人予約も存在する。
予約時刻は施設所在地のAsia/Tokyoで扱い、営業日は月曜から金曜とする。祝日は営業日から除外しない。
無料個人の予約変更では、既存予約のキャンセルを先に確定してから、代替予約と利用枠戻しを処理する。利用枠残数0・施設には空きがあるケースも存在し、施設定員を超えるケースとは区別する。
初回利用の新規法人予約では、利用許可チェック・電子鍵発行・チェックインは別の処理で、処理開始時にはいずれも未完了とする。「後」は完了より厳密に後で、同時処理や過去の完了記録の流用は認めない。

- R01: 法人予約の1件あたりの利用時間は、4時間を上限とする。
- R02: 無料個人の予約変更で、既存予約のキャンセルが確定し、利用枠残数0かつ施設に空きがある場合、同じ変更受付処理が終了するまでに、キャンセル分の利用枠戻しを必ず完了する。
- R03: 正の利用料金を支払済みの通常の法人予約で、利用開始24時間以上前のキャンセルには、キャンセル料を0円とする。
- R04: 開始まで24時間未満の一般の新規予約は、原則として受け付けない。ただしR18を例外とする。
- R05: 保守による受付停止中の施設について、新規予約を受け付けない。
- R06: 有料法人予約のキャンセルで返金が生じる場合は、翌営業日までに金銭の返金処理を行う。
- R07: 施設が通常稼働中の初回利用の新規法人予約は、利用開始時刻までに、利用許可チェック・電子鍵発行・チェックインをそれぞれ必ず完了する。
- R08: 同時予約定員1件の個室について、どの予約受付処理の終了時にも、同じ時間帯の確定予約は1件以下にする。
- R09: 利用者が「頻繁に」予約変更を繰り返した場合は、その利用者の次の予約受付を制限する。回数と集計期間は、この仕様書では定めていない。
- R10: 無料個人予約の1件あたりの利用時間は、2時間を上限とする。
- R11: 通常個人予約で、開始15分後の時点でもチェックインがない場合、その時点で予約を必ず取消状態に遷移させる。
- R12: R02の条件の無料個人予約変更では、キャンセル分の利用枠戻しを実行できるのは、同じ変更の新規代替予約が確定した後だけとする。
- R13: 予約IDは予約ごとに一意とし、予約日時の変更だけでは変更しない。
- R14: R03と同じ、正の利用料金を支払済みの通常の法人予約・開始24時間以上前のキャンセルには、支払済み利用料金の30%をキャンセル料として必ず徴収する。
- R15: 予約の時間帯の終了時刻と次の予約の開始時刻が一致する場合、その境界だけを理由に重複予約と判定しない。
- R16: 無料個人予約のキャンセルでは、金銭の返金処理を行わない。利用枠の返却は金銭返金とは別の処理である。
- R17: R07の新規法人予約で、電子鍵を発行できるのは、同じ予約の利用許可チェックが完了した後だけとする。
- R18: R04の例外として、施設が通常稼働中で空きがあり管理者が承認した緊急利用は、開始まで24時間未満でも新規予約を受け付ける。保守による受付停止中にはこの例外を適用しない。
- R19: 保守による受付停止より前に確定した既存予約は、受付停止だけを理由に取り消さない。R05の新規受付とは区別する。
- R20: R02の条件の無料個人予約変更で、新規代替予約を確定できるのは、同じ変更の利用枠戻しが完了して口座残数に反映された後だけとする。利用枠の借り越しは認めない。
- R21: 新規受付の先着順は受付時刻で決める。同一時刻の複数要求の順番は、この仕様書では定めていない。
- R22: 施設が通常稼働中で開始まで24時間以上あり、同時予約定員1件の個室の同じ時間帯に確定予約が1件ある場合でも、追加要求を必ず新しい確定予約にする。既存の確定予約は取消・移動せず維持する。
- R23: 通常個人予約は、チェックインの有無によらず、開始時刻から終了時刻直前まで必ず確定状態のまま維持する。取消状態にはしない。
- R24: 利用料金には、0円以上の整数円だけを登録する。
- R25: R07の新規法人予約で、利用許可チェックを開始できるのは、同じ予約のチェックインが完了した後だけとする。
- R26: 予約の連絡先は、予約者本人が参照できるようにする。
- R27: 施設IDは施設ごとに一意とし、名称変更では変更しない。
- R28: R07の新規法人予約で、チェックインを完了できるのは、同じ予約の電子鍵発行が完了した後だけとする。鍵なしの窓口チェックインは、この区分には用意しない。
