# 会員・権限管理システムの仕様書

すべて同一バージョンのシステムに適用する要件である。ID順の優先順位はない。例外は対象要件を明示したものだけを認める。
一般利用者、サポート担当者、システム管理者は排他的なロールとする。法人契約と個人無料契約も排他的な区分とする。
サービス連携専用アカウントは実際に運用する。多要素認証の必須設定は、電話認証の登録有無とは別の設定値である。
招待リンクはすべて同じ種別で、手動取消のない場合を扱う。R08・R09の時間は同じ発行時刻からの経過時間である。

- R01: 有効なサポート担当者は、担当テナントの会員情報を閲覧だけでき、電話番号を含む会員情報の書き換えは一切できない。
- R02: 有効なサポート担当者は、担当テナントの会員情報の電話番号をいつでも書き換えられる。
- R03: 退会完了処理の終了時には、その会員の連絡先メールアドレスを保存領域から直ちに完全削除し、同じメールアドレスを保持しない。
- R04: 退会完了処理後も、その会員の同じ連絡先メールアドレスを元の値のまま180日間保持し、削除しない。
- R05: セキュリティ保護対象のアカウントはすべて、多要素認証の必須設定を有効にする。
- R06: 多要素認証の必須設定を有効にするには、電話認証が登録済みであることを必須条件とする。
- R07: サービス連携専用アカウントはすべてセキュリティ保護対象に含める。これらのアカウントでは電話認証を登録できず、登録済みにはしない。
- R08: 招待リンクは発行から24時間未満の間は常に有効とし、24時間に達した時点で初めて失効させる。
- R09: 同じ招待リンクは発行から12時間に達した時点で必ず失効させ、それ以降は無効とする。
- R10: 有効なシステム管理者には監査ログの閲覧を許可する。
- R11: 有効な一般利用者には監査ログの閲覧を許可しない。
- R12: ロック中のアカウントでは、原則としてパスワードによるログインを拒否する。ただしR13を例外とする。
- R13: R12の例外として、電話認証で本人確認を済ませた一回限りの復旧チケットを持つロック中のアカウントには、そのチケットを使ったパスワードログインを1回許可する。
- R14: 法人契約の利用者には請求書CSVのダウンロードを許可する。
- R15: 個人無料契約の利用者には請求書CSVのダウンロードを許可しない。
- R16: 「異常なアクセス」を検知したらアカウントをロックする。どの回数・時間・接続元で異常と判断するかは、この仕様書では定めていない。
- R17: サポート担当者の緊急対応操作には「責任者」の許可を必要とする。責任者のロール・所属・代理の範囲は、この仕様書では定めていない。
- R18: ログイン失敗を記録する場合は、失敗時刻をUTCの日時で保存する。
- R19: ログアウトが成功したら、そのログインセッションを直ちに無効にする。
- R20: 会員情報の読み取りでは、許可されたテナントIDと対象レコードのテナントIDが一致することを確認する。
