# 受注・出荷システムの仕様書

すべて同一バージョンのシステムに適用する要件である。ID順の優先順位はない。例外は対象要件を明示したものだけを認める。
通常便と速達便、国内配送と海外配送、前払いと後払いはそれぞれ排他的な区分とする。後払いの通常在庫品注文も実際に受け付ける。
「支払確定」は代金の支払いが確定した状態で、「注文受付」とは異なる。「出荷可能状態」は出荷前の倉庫の状態で、「出荷完了」とは異なる。
梱包済みでも未出荷かつ注文受付から30分以内の注文は存在する。以下の「すべて」「必ず」「一律」には、明示していない例外はない。

- R01: 支払確定済み・未出荷の通常便注文について、受付から30分以内のキャンセルは、梱包完了済みでも必ず受け付ける。
- R02: 支払確定済み・未出荷の通常便注文について、梱包完了済みの注文のキャンセルは、受付からの経過時間によらず一律拒否する。
- R03: 国内配送の通常便注文の請求書では、送料欄の金額を必ず500円とする。
- R04: 国内配送の通常便注文の請求書では、同じ送料欄の金額を必ず0円とする。
- R05: 配送処理対象となる通常在庫品注文はすべて、出荷前に倉庫の出荷可能状態に入れる。
- R06: 通常在庫品注文が倉庫の出荷可能状態に入るには、支払確定済みであることを必須条件とする。
- R07: 後払いの通常在庫品注文はすべて配送処理対象に含める。後払い注文の支払確定は出荷完了後にのみ行い、出荷前に支払確定済みにはしない。
- R08: 倉庫で出荷完了を確定した注文について、その確定処理の終了時には、注文レコードの追跡番号欄に空ではない追跡番号を必ず保存する。
- R09: 倉庫で出荷完了を確定した注文について、その確定処理の終了時には、同じ注文レコードの追跡番号欄を必ず空にする。
- R10: 未払いの通常便注文について、出荷前のキャンセルを受け付ける。
- R11: 未払いの速達便注文について、出荷前でもキャンセルを拒否する。
- R12: 国内配送注文の住所変更は原則として未出荷であれば受け付ける。ただしR13を例外とする。
- R13: R12の例外として、梱包完了済みの国内配送注文の住所変更は拒否する。
- R14: 送料無料会員の国内配送・速達便注文の送料は0円とする。
- R15: 海外配送の通常便注文の送料は1200円とする。
- R16: 出荷後の返品申請は、出荷完了から「長期間」経過している場合に拒否する。「長期間」の日数はこの仕様書では定めていない。
- R17: 注文履歴の日付検索に使う「営業日」は会社カレンダーに従う。会社カレンダーの曜日・祝日・休業日はこの仕様書では定めていない。
- R18: 注文IDは注文ごとに一意とし、受付後に変更しない。
- R19: 各注文明細の数量には、1以上99以下の整数だけを受け付ける。
- R20: 在庫の引当処理で、保有在庫数を負の数にしない。
