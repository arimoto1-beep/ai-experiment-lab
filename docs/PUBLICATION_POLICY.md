# 実験データの公開方針

## AI実験室 #8

公開するのは固定課題・保存済み差分から復元できることを示すハッシュ、
二段階レビューの実装と手順、初回レビュー原文、レビュー前後のコード差分、
公式報酬と失敗項目の要約、時間・使用量・API換算費用、反事実検証の要約である。
公式課題のコピー、検証器の実装、生ログ、CLIの生ストリーム、認証情報、
個人用の絶対パスは Git に含めない。公開用の要約には試行 ID と相対パスを使う。
非公開採点器やその結果をレビュー担当モデルに渡さない実行条件は維持する。

## 仕様矛盾検出ベンチマーク

`benchmarks/spec_contradictions/answer_keys/` と
`benchmarks/spec_contradictions_set2/answer_keys/` の計6ファイルは、架空の仕様を
対象にした過去の実験の公開正解データである。これらの課題は、今後の未知問題に対する
盲検評価には使用しない。採点時は正解をモデルの入力と作業環境から隔離する。

## agentic_dev

課題文、初期コード、公開テスト、実験基盤、固定ハッシュ、集計と分析レポートを公開する。
非公開テストと参照実装は公開しない。認証情報は専用 Docker ボリュームに置き、
`results/` の生ログと作業成果物も Git に含めない。

公開リポジトリだけでは、非公開テストを使う採点と参照実装に依存する検証は実行できない。
その検証には、公開済みの manifest に記録したハッシュと一致する非公開ファイルを
別途用意する必要がある。欠けている場合、実験ランナーは実モデルを起動する前に停止する。
固定済みの課題、プロンプト、採点方法、20試行の結果は公開方針の記録によって変更しない。
