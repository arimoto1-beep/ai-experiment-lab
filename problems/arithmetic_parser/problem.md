# 課題: 四則演算の数式を計算するパーサーを実装する

`solution.py` に次の関数を実装してください。

```python
def calculate(expression: str) -> float:
```

`expression` は四則演算の数式を表す文字列です。数式を解析して計算し、結果を `float` で返してください。

## 数式の文法

1. **数値**: 整数または小数です。数字は半角の `0`〜`9` だけを使います。
   - 整数部分は1桁以上です。先頭の `0` はあってもかまいません（`007` は `7`）。
   - 小数点は1つの数値に1つまでです。小数点の前後には数字が必要です（`1.` と `.5` は不正）。
   - 指数表記（`1e3`）、桁区切り（`1_000`）、16進数（`0x1F`）は対象外で、不正です。
2. **二項演算子**: `+`（加算）、`-`（減算）、`*`（乗算）、`/`（除算）の4種類です。
3. **単項演算子**: `+` と `-` です。被演算子（数値または開き括弧）の直前に置けます。単項演算子を連続して置いてもかまいません（`--3` は `3`、`+-3` は `-3`、`2*-3` は `-6`）。
4. **括弧**: `(` と `)` です。入れ子にできます。少なくとも50段の入れ子に対応してください。括弧の中が空の `()` は不正です。
5. **優先順位**: 単項演算子、`*` と `/`、`+` と `-` の順に強く結びつきます。
   - 同じ優先順位の二項演算子は、左から順に計算します（`8-4-2` は `(8-4)-2`、`8/4*2` は `(8/4)*2`）。
   - 単項演算子は乗除算より強く結びつきます（`-2*3` は `(-2)*3`）。
6. **空白**: 半角スペース、タブ、改行は空白です。数値・演算子・括弧の間と、式の先頭・末尾には、空白を何個入れてもかまいません。ただし数値の内部（`1 2`、`1 .5`、`1. 5`）には空白を入れてはいけません。
7. **不正な並び**: 演算子を書かずに数値や括弧を並べること（`2(3)`、`(1)(2)`、`1 2`）と、二項演算子を連続して置くこと（`1**2`、`1*/2`）は不正です。

## 戻り値と例外

- **正しい数式**: 結果を `float` で返します。整数の結果でも `5.0` のように `float` にしてください。判定は相対誤差 `1e-9` 以内で行います（期待値が `0` の場合は絶対誤差 `1e-12` 以内）。
- **不正な構文**: `ValueError` を送出します。空の式、空白だけの式、演算子・数値・括弧の欠落や過剰、括弧の対応の不一致、課題文に無い文字（例: `a`、`^`、`%`、`,`、`=`、`_`、`x`）を含む式が該当します。
- **ゼロ除算**: 構文が正しく、除数（`/` の右辺）が `0` になる式は `ZeroDivisionError` を送出します。`0.0` や `-0` も `0` とみなします。
- **構文の検査が先**: 式全体の構文が不正であれば、ゼロ除算を含んでいても `ValueError` を送出してください。例えば `1/0+` は `ValueError` です。

## 禁止事項

- `eval()`、`exec()`、`compile()`、`__import__()` を使ってはいけません。
- `ast` モジュールを import してはいけません。
- sympy などの外部の数式評価ライブラリを使ってはいけません。
- 標準ライブラリだけを使ってください。

## 例

| 式 | 結果 |
|---|---|
| `"1 + 2 * 3"` | `7.0` |
| `"(1 + 2) * 3"` | `9.0` |
| `"8 - 4 - 2"` | `2.0` |
| `"7 / 2 * 2"` | `7.0` |
| `"-2 * -3"` | `6.0` |
| `"0.1 + 0.2"` | 約 `0.3` |
| `"1 2"` | `ValueError` |
| `"1 / (2 - 2)"` | `ZeroDivisionError` |
| `"1 / 0 +"` | `ValueError` |
