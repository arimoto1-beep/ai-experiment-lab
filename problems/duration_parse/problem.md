# 課題: 期間文字列を秒数に変換する

`solution.py` に次の関数を実装してください。

```python
def parse_duration(text: str) -> int:
```

`text` は期間を表す文字列です。期間の合計秒数を `int` で返してください。仕様に合わない入力には `ValueError` を送出してください。

## 仕様

1. 期間は「整数＋単位」の要素を1つ以上並べたものです。単位は次の4種類で、大文字・小文字は区別しません。
   - `d`: 1日 = 86400秒
   - `h`: 1時間 = 3600秒
   - `m`: 1分 = 60秒
   - `s`: 1秒 = 1秒
2. 整数部分は10進数の0以上の整数です。先頭の `0` があってもかまいません（`007s` は 7秒）。
3. 整数と単位の間に空白を入れてはいけません（`1 h` は不正）。
4. 要素の順序は任意です（`30m1h` は 5400）。
5. 要素と要素の間には、空白（半角スペース）を0個以上入れてもかまいません（`1h30m`、`1h 30m`、`2d   3h` はいずれも有効）。
6. 文字列の先頭と末尾の空白は無視します（`"  1h  "` は 3600）。
7. 同じ単位が2回以上現れた場合は不正です（`1h2h`、`1H1h` は不正）。
8. 次の入力は不正です。`ValueError` を送出してください。
   - 空文字列、空白だけの文字列
   - 単位のない数字（`90`）、数字のない単位（`h`、`h1`）
   - 小数（`1.5h`）、負の値（`-1h`）、先頭に `+` を付けたもの（`+1h`）
   - 未知の単位（`1w`、`1ms`）、整数と単位の間の空白（`1 h`）
   - 末尾が単位で終わらないもの（`1h30`）
9. 戻り値は `int` 型です。

## 例

| 入力 | 戻り値 |
|---|---|
| `"90s"` | `90` |
| `"1h30m"` | `5400` |
| `"2D 3H"` | `183600` |
| `"30m1h"` | `5400` |
| `"  1h  "` | `3600` |
| `"0s"` | `0` |
| `"007s"` | `7` |
| `"1h2h"` | `ValueError` |
| `"1.5h"` | `ValueError` |
